# Contributing to Organic Semiconductor Discovery

Thank you for your interest in this project!

## About This Repository

This repository contains the computational workflow and analysis code for a two-paper programme (RSC Digital Discovery; J. Chem. Inf. Model.). The code is provided to ensure reproducibility and FAIR compliance.

## Reporting Issues

If you encounter any issues with the code or data:

1. Check the [Zenodo repository](https://doi.org/10.5281/zenodo.18201813) for the complete datasets
2. Review the `COMPUTATIONAL_WORKFLOW.md` for detailed methodology
3. Open an issue on GitHub with:
   - Description of the problem
   - Steps to reproduce
   - Your environment (Python version, OS, etc.)

## Code of Conduct

Please be respectful and professional in all interactions.
